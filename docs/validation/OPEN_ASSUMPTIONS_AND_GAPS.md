# Explicit Open Assumptions, Wet-Lab Gaps & Operational Boundaries

In strict adherence to GxP epistemic honesty, this document separates **verified software capabilities present in this repository** from **open wet-lab, OT infrastructure, and GMP facility prerequisites** that are NOT present in the codebase and must be executed before any GMP clinical or commercial deployment.

| Domain | Verified Codebase Capabilities (Present in Repo & Tested) | Open Wet-Lab / GMP Facility Assumptions & Gaps (Not Yet Present) |
| --- | --- | --- |
| **Bioprocess Kinetics & Organism Calibration** | Synthetic *E. coli* BL21 calibration (`kappa_rel = 38.18`, seed-42 max error `4.39%`, `GAM-86` `kd_r2 = 0.7320`, `kla_r2 = 0.9806`, `mu_r2 = 0.9925`) plus external public CHO-K1 benchmark validation (`Uhlendorff et al., 2026`, `8.61 / 10.00 -> GO (PASS)`, `pooled_test_wmse = 23.3272`). | No proprietary Eli Lilly mammalian/microbial cell-line batch histories, GMP media lots, seed-train variability datasets, or site-specific recombinant product titers are present. Wet-lab iDoE/historical re-calibration is required per molecule and cell line. |
| **Scale-Up Hydrodynamics (`5 L` -> `1000 L`)** | Intensive hydrodynamic invariants `(P_g/V, v_tip, v_s)` verified mathematically (`test_scale_invariance_1000L`) and in closed-loop simulation (`hybrid_norm_rmse = 0.03687` vs `0.39081` at `1000 L`). | Real `50 L` / `1000 L` stainless or single-use bioreactor mixing-time gradients, sparger geometry differences, foam/antifoam rheology shifts, and headspace backpressure effects have not been wet-lab characterized in this repo. |
| **OT / LIMS & Historian Integration** | Deterministic schema/unit parsers and quarantine audit logging (`AllotropeASMAdapter`, `OpcUaSnapshotAdapter`, `MqttTelemetryAdapter`, `LimsBatchAssayAdapter`) verified against synthetic JSON payloads (`test_ot_lims_adapters_valid_roundtrips_and_quarantine_alcoa_chain`). | Live network connectors, mTLS/X.509 OPC-UA certificates, MQTT broker ACLs, DeltaV/Syncade/PI Historian polling, and LabWare/Benchling LIMS REST/SQL drivers are not wired. Hardware-in-the-loop (HIL) OT IQ/OQ is open. |
| **Authentication, RBAC & Identity Provider (IdP)** | Structural 2FA schema checks (`Part3TwoFactorESig`), human-only actor ID enforcement (`validate_human_qa_id`), and single-use `UsedTwoFactorChallengeRow` replay blocking in SQLite. | No live enterprise OIDC/SAML IdP (e.g., Azure AD / Okta), cryptographic WebAuthn/FIDO2 assertion verification, LDAP group-to-QA-role binding, or FastAPI OAuth2 bearer middleware is integrated. |
| **Persistence & Backup High Availability** | SQLAlchemy ORM (`api/db.py`) supporting `DATABASE_URL`, SQLite persistence round-trips, SHA-256 chain verification (`verify_audit_chain`, `verify_part11_decision_chain`), and `ekf_gate_state_json` migration. | Production managed PostgreSQL HA clustering, immutable WORM/S3 Object Lock archival, automated disaster recovery RPO/RTO drills, and OS-level clock NTP attestation remain infrastructure prerequisites. |
| **LLM CAPA Provider & External Evals** | Pluggable `CapaDraftProvider` with offline zero-secret `DeterministicCiCapaProvider`, deterministic `validate_capa_draft` guardrails, and 8-case shadow `UCR` + `wilson_ci_95` harness. | No live hosted enterprise LLM endpoint, VPC private-link gateway, prompt-injection firewalling against free-text LIMS notes, or prospective QA usability study with human bioprocess engineers has been executed. |
| **Observability & MLOps Orchestration** | Offline-safe `TwinTelemetryRecorder` (`/metrics` Prometheus text + in-memory OTel spans), Medallion ETL (`mlops/medallion.py`), and `LocalMlflowCompatibleTracker` (`mlops/registry.py`) tested with zero external daemons. | Live OpenTelemetry Collector OTLP export, Prometheus scraping/Alertmanager paging, enterprise Prefect Server workers, and remote MLflow Artifact Store signing are optional extras not deployed in this repo. |
| **Regulatory Validation Package Execution** | Automated AST/test RTM (`scripts/generate_rtm.py`), CSA/GAMP 5 risk grid, 7-step credibility framing, and ICH Q14/Q12 PACMP verified in CI. | Formal site Quality Assurance sign-off, SOP integration, User Requirements Specification (URS) approval, and wet-lab PQ execution protocols remain organizational GMP activities outside the git repository. |
